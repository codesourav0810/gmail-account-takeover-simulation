# Gmail Scam Awareness Simulation

An interactive educational simulation demonstrating how a fake Gmail
verification/OTP scam can lead to account takeover.

## ⚠️ Disclaimer

This project is created strictly for cybersecurity awareness and
educational purposes.

It uses completely simulated interfaces and dummy data. It does not
interact with real Gmail accounts, collect credentials, capture OTPs,
or perform any real account takeover.

## 🎯 Project Objective

The objective of this project is to demonstrate how victims can be
manipulated through fake verification messages and malicious links,
and how sensitive information can be misused by scammers.

## 🖥️ Features

- Interactive landing page
- Gmail scam awareness simulation
- Victim/User screen
- Simulated attacker screen
- Synchronized simulation
- Fake verification workflow
- Simulated OTP verification
- Safety measures section
- Cybersecurity awareness information
- Responsive interface

## 🔄 How the Simulation Works

1. The user receives a simulated Gmail-related message.
2. The message contains a suspicious verification link.
3. The user interacts with the simulated link.
4. A fake verification process is displayed.
5. A simulated OTP is entered.
6. The attacker-side screen demonstrates how the information
   could be misused.
7. The simulation concludes with cybersecurity safety measures.

## 🛡️ Safety Measures

- Never click suspicious links.
- Verify the sender before taking action.
- Never share OTPs with anyone.
- Check the URL before entering sensitive information.
- Enable two-factor authentication.
- Report suspicious messages.
